## 왜 터미널 & 대시보드 감성인가?

개발자 블로그는 단순한 텍스트 뷰어를 넘어 **개발자의 아이덴티티를 보여주는 워크스페이스**입니다. 이 블로그는 두 가지 모드를 완벽하게 지원하도록 설계되었습니다.

1. **Cyberpunk Dark Mode (기본)**: 딥 네이비/블랙 배경(`#060911`) 위에 시안(`#00f3ff`), 퍼플(`#b537f2`), 에메랄드(`#00ff9d`) 네온 포인트와 그리드 라인을 배치해 HUD 대시보드 느낌을 살렸습니다.
2. **Clean Terminal Light Mode**: 낮 시간대나 긴 글 가독성을 선호하는 독자를 위해 고대비 슬레이트 & 화이트 톤으로 즉시 전환됩니다.

## 메인 화면 터미널 명령어 사용법

홈 화면 상단의 터미널 위젯은 단순한 장식이 아니라 **실제로 동작하는 CLI 인터프리터**입니다. 입력창에 아래 명령어를 직접 타이핑해 보세요!

```bash
$ help          # 사용 가능한 전체 명령어 출력
$ whoami        # 블로그 운영자(nicebyy) 프로필 정보 조회
$ skills        # 주요 기술 스택 및 숙련도 게이지 출력
$ ls            # 최근 작성된 블로그 포스트 리스트 확인
$ theme         # 다크 모드 / 라이트 모드 즉시 토글
$ clear         # 터미널 출력 로그 초기화
```

## 커스터마이징 포인트

내 프로필 정보나 기술 스택, 소셜 링크를 수정하고 싶다면 프로젝트 내 `src/config/site.ts` 파일 하나만 열어서 값을 변경하면 사이트 전체에 즉시 반영됩니다.
